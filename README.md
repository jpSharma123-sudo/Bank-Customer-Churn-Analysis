# Bank Customer Churn Analysis

## Project Overview
This project analyzes bank customer churn using SQL, MySQL, and Power BI. The objective is to understand customer behavior, identify churn patterns, and generate insights that can support customer retention strategies.

## Business Problem
Customer churn affects customer relationships and long-term business growth. This project explores customer demographics, credit scores, account balances, product usage, and customer activity to understand churn patterns.

## Tools and Technologies
- SQL
- MySQL
- Power BI
- Microsoft Excel

## Project Objectives
- Analyze customer churn and retention patterns.
- Evaluate customer behavior across demographic and geographic segments.
- Investigate relationships between credit scores, account activity, and churn.
- Present business insights through SQL queries and Power BI visualizations.

## Project Structure
- `SQL/` – Database setup and analysis queries.
- `PowerBI/` – Power BI dashboard.
- `Documentation/` – Project report.
- `Presentation/` – Project presentation.
- `Dashboard_Screenshots/` – Dashboard screenshots.

## SQL Analysis
The project includes database setup, data loading, customer analysis, aggregation, and business questions related to churn and retention.

## Power BI Dashboard
The Power BI report provides visual analysis of customer churn and retention patterns. Dashboard screenshots can be added to the `Dashboard_Screenshots` folder.

## Business Recommendations
- Investigate customer segments with higher churn rates.
- Evaluate targeted customer retention campaigns.
- Monitor customer activity and product usage.
- Use data-driven insights to improve customer engagement.

## Conclusion
This project demonstrates the use of SQL and Power BI for customer churn analysis and business intelligence reporting.
